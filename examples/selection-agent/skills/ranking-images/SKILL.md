# 排行榜图片

贴 `score_and_save` 或 `score_candidates` 返回的 `markdown` 时，表里已经有「图片」列。原样贴上。

- 不要删掉图片列，不要改成文字链接，也不要自己重画表。
- 有图的格子是 `![](图片地址)`，地址是搜索页主图。
- 没有图的格子是「—」。不要补图，不要编地址。
- 其他列的数字不要改。总分、需求、趋势、竞争、利润后面的方块条原样保留，不要删掉，也不要改成纯数字。「上架」保持加粗。
