# 选品台模拟后台视觉升级

状态：已实现。范围：`examples/selection-agent/seller-backend/index.html`（单文件视觉 + 信息结构）。计划：`docs/superpowers/plans/2026-10-27-seller-backend-ops-console.md`。

## 背景

selection-agent 演示用本地模拟卖家后台（`http://127.0.0.1:7455/`，账号 `seller` / `demo`）。流程已能跑通：登录 → 准备 → 编辑链接 → 入库 → 广告 → 发布到德国站 → 买家页。

当前页面视觉偏草稿：系统字体、灰底白卡片、侧栏品牌叫「Studio DE」、字段挤在一起，给跨境老板演示时不够「正式运营台」。

用户已定：

- 方向：国内跨境工具感（中文运营台、状态条、步骤清晰）
- 范围：视觉 + 信息结构；核心按钮文案尽量保留
- 品牌名：**选品台**
- 做法：**A. 单文件视觉重做**，不拆 css/js，不多页路由

## 目标

- 登录页与后台壳子一眼是「选品台」运营工具，不是白盒 demo。
- 顶部展示站点（Amazon.de）、当前 SKU、上架状态。
- 主区有清晰的上架进度（准备 → 编辑链接 → 入库 → 广告 → 发布）。
- 准备 / 编辑 / 入库 / 广告 用卡片分组与状态标签，信息更好扫。
- 买家页更像商品详情；演示说明降为次要文案。
- **agent 现有点击路径不变**：侧栏按钮可见文字、`data-tab`、表单 `id`、`发布到德国站` 按钮原文、`#shop` 买家页都保留。

## 非目标

- 不改 `serve.py`、`case.json`、`live.json`、`images.json` 协议。
- 不改登录账号密码、发布 API。
- 不改 `skills/select-to-shelf` 或 AGENTS.md（除非实现时发现可见文案被迫改了，再单独说明）。
- 不做真实亚马逊 UI 仿冒（避免山寨橙顶栏）。
- 不拆多文件、不做路由多页、不加真实图表/权限系统。
- 不改 tah 源码。

## 视觉方向

国内跨境运营台，不是 Amazon Seller Central 克隆。

| Token | 用途 |
| --- | --- |
| 品牌 | 「选品台」；副文案「德国站 · 本地模拟」 |
| 顶栏 | 浅色或近白，带细分割；右侧账号 / 退出 |
| 侧栏 | 深色窄栏，导航项高亮清晰 |
| 主色 | 稳重蓝绿系（运营台常见），主按钮实心；避免紫渐变、奶油衬线、报纸栏 |
| 字体 | 中文优先系统栈（PingFang SC / Noto Sans SC / Segoe UI），字号层级明确 |
| 状态 | 草稿 / 已上架 / 竞品只读 / 未投放 等用色块标签 |
| 进度 | 水平步骤条，当前步高亮，已完成可勾选样式 |

现有 CSS 里 `.shot` 后有一段无选择器的残留规则，一并清掉。

## 页面结构

### 登录

- 标题改为「选品台」
- 副标题保留「本地模拟、不连真实卖家账号」语义
- 演示账号提示保留 `seller` / `demo`
- `#login-form`、`#account`、`#password`、`#login-error` 保留

### 壳子

- 侧栏品牌：选品台 · 德国站（替换 Studio DE）
- 导航按钮文字不变：商品 / 准备 / 编辑链接 / 入库 / 广告 / 买家页面；`data-tab` 不变
- 主区顶：标题 + 当前账号；旁侧或下方加 **进度条**（准备 → 编辑链接 → 入库 → 广告 → 发布）
- 顶栏或标题行展示：Amazon.de · 当前 SKU · 状态标签
- `#logout`、`#heading`、`#who` 保留

### 商品

- 表格保留列：SKU/ASIN、标题、售价、状态
- 状态标签样式加强；竞品行保持「竞品，只读」

### 准备

- 三个卡片分组不变（报价 / 试样 / 链接）
- 每张卡标题旁加状态标签（已报价 / 已记录 / 草稿等，仍读 `case.json`）
- 字段可用小网格展示关键金额，避免一长句糊在一起；数据来源与字段名不变

### 编辑链接

- 左：基本信息（标题、售价、配送、类目、五点）
- 右：随链接带上（主图说明、GTIN、VAT 等）
- 主按钮文案仍为「发布到德国站」；已发布时「已发布」逻辑不变
- `#edit-form`、`#title`、`#price`、`#ship`、`#category`、`#bullets`、`#publish`、`#pack` 保留

### 入库 / 广告

- 单卡 + 醒目状态标签（例如「已建单 · 件数未填」「未投放」）
- 说明文案语义不变

### 买家页面 / `#shop`

- 主图更大、标题与欧元价层级更强
- 演示说明（VAT、GTIN、不能下单）收到次要区域
- `#cart`、购物车提示逻辑不变

## 不变清单（回归）

实现后人工点一遍：

1. `seller` / `demo` 能登录
2. 侧栏六个入口能切换
3. 准备页能读到 `case.json`
4. 编辑页发布 → `POST ./publish` → 状态变已上架 → 跳买家预览
5. `#shop` 显示已发布商品；购物车仍提示不能下单
6. agent skill 里写的按钮字：准备、编辑链接、入库、广告、发布到德国站、买家页面 —— 页面上仍能找到同名控件
