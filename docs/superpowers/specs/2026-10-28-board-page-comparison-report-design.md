# 选品结果看板：表格式对比报告

状态：已定稿，待实现。范围：`examples/selection-agent/lib/board-page.ts` 生成的「选品结果」HTML（及由其截出的 PNG）。参考稿：`.superpowers/mockups/board-report-v1.html`（方向 A）。

## 背景

selection-agent 在评分落盘后用 `board-page` 拼一页 HTML，再截图贴进聊天。当前页是奶油底（`#f4f1ea`）+ 纵向商品卡片，四维条埋在卡内，横比弱，截图不像正式选品报告。

用户已定：

- 目标气质：**冷静数据报告**（浅灰底、深字、蓝/墨绿强调）
- 布局：**表格式对比榜**（方案 A；否决紧凑 B、大图 C）
- 范围：**整页统一**（结论、排行、说明、缺口同一视觉）
- 不做：seller-backend 改版、改评分逻辑、改 tah、拆多文件路由

## 目标

- 一眼能横比候选的需求 / 趋势 / 竞争 / 利润。
- 结论与上架/观察/放弃计数仍在页顶。
- 说明、缺口与榜单同属一页报告，不再像附录随意贴。
- 截图宽度习惯约 **840px**；高度仍由内容估算，供 `board-shot` 使用。

## 非目标

- 不改 `score` / `recommend` / 报告 JSON 字段语义。
- 不改 `render_board` / `score_and_save` 的调用约定（仍吃同一套 rows / conclusion / notes / gaps / images / siteLabel）。
- 不仿冒 Amazon Seller Central 橙顶栏。
- 不做交互排序、筛选、折叠（仍是静态截图页）。
- 不引入外链字体 CDN（可用系统栈 + 可选本地已有字体名作 fallback）。

## 视觉方向

| Token | 用途 |
| --- | --- |
| 背景 `--bg` | 冷灰蓝 `#e8ecf1` 一带，告别奶油纸 |
| 纸面 `--paper` | 近白 `#f7f9fb`，分区用细边框而非重阴影 |
| 主文 `--ink` | `#121820` |
| 次文 `--muted` | `#5c6b7a` |
| 强调 `--accent` / 条 `--bar` | 墨绿蓝 `#0c5c6b` / `#1a6f7c` |
| 上架 | 绿字绿底标签 |
| 观察 | 琥珀标签 |
| 放弃 | 灰标签 |
| 圆角 | 分区 8px；标签 4px；避免大 pill 堆砌 |
| 字体 | `"PingFang SC", "Noto Sans SC", "Segoe UI", system-ui, sans-serif`；数字 `tabular-nums` |

参考实现气质见 mockup A；实现时以本 spec 为准，mockup 仅作视觉对照。

## 页面结构

### 顶栏 meta

- 左：`siteLabel`（如 `Amazon.de`；可带「德国站 / 美国站」语义，有则显示）
- 右：固定次文「选品结果」或等价短戳
- 无 `siteLabel` 时不留空占位行

### 结论区（hero）

- 左：`conclusion` 一句（现有 lead）
- 右：三格计数——上架 / 观察 / 放弃（逻辑仍用 `boardCaption` / 现有 counts）
- 两列网格；窄宽仍以 840 为设计宽

### 排行对比表

表头：`#` ·（图）· 商品 · 动作 · 总分 · 需求 · 趋势 · 竞争 · 利润

每行：

- 排名序号
- 商品图：有 `images[id]` 则 `<img>`，否则占位块（尺寸约 44×44，圆角 6）
- 标题 + 次行可显示 `id`（ASIN）；标题转义规则不变
- 动作标签：上架 / 观察 / 放弃（及未知动作的中性样式）
- 总分：三位小数，现有 `total`
- 四维：每格为「标签 + 数值 + 短条」；缺维（`gaps` 含对应 gap 文案）显示 `—`、条宽 0
- 「上架」行可用极淡绿底，便于扫

条宽算法保持现有 `barWidth` + `WEIGHTS` / raw 检测，不改数值含义。

### 说明

- 仍解析 `notes` 为「为什么 / 要验」结构（现有 `noteOf`）
- 两列网格卡片；无 notes 则整段不渲染

### 缺口

- `gaps` 以标签条展示；无则不渲染

## 实现约束

- **单点改动**：主要改 `boardPage()` 返回的 HTML/CSS；`boardCaption`、行类型、height 估算跟新布局微调。
- **测试**：`board-page.test.ts` 断言关键结构（如排行表、动作类名、转义）；按需更新快照式字符串匹配。
- **截图**：`board-shot` / `render-board` 路径不变；实现后用一条真实报告跑通 PNG，人工看一眼。
- **多站点**：仅展示传入的 `siteLabel`；不在看板里做站点切换控件。

## 验收

1. 打开生成的 HTML（或截图）：灰底报告感，无奶油底。
2. 多条候选时，四维可在同一行横比。
3. 结论、说明、缺口仍出现且风格一致。
4. 现有单测通过；演示链路仍能 `![选品结果](路径)`。

## 否决的备选

- **B 紧凑表**：行过矮，演示截图可读性差（mockup：`board-report-v2-dense.html`）。
- **C 大图优先**：削弱四维横比，与「商品对比榜」目标不符。
- **主推+其余榜**：对比感弱，已在方案阶段否决。
