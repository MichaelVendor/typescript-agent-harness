# Skills (Agent Skills) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Cursor/Claude/DSH-aligned Agent Skills to `tah`: discover `SKILL.md`, inject a catalog into the system prompt, load bodies via `skill` tool or `/name`, with optional resource listing.

**Architecture:** All logic lives in `packages/cli/src/skills/*`. Boot discovers and merges skills, registers the `skill` tool, and appends a catalog section to `buildSystemPrompt`. `ChatHost.send` strips/matches `/kebab-name` and appends rendered skill payloads to the **model-facing** prompt while the UI keeps the original user text. Watch/reload covers project skill dirs and `~/.tah/skills`.

**Tech Stack:** TypeScript (Node ≥22), `node:test`, existing `@typescript-agent-harness/tools` `Tool` type, no new YAML dependency (minimal frontmatter parser).

**Spec:** `docs/design/skills.md`

## Global Constraints

- Implement only in `packages/cli` (no new package).
- No `tah skill add`, no `capabilities.skills`, no auto-exec of `scripts/`.
- Project skill roots only when `package.json` depends on `@typescript-agent-harness/cli`.
- Bad skill files: warn + skip, never fail boot.
- Target release line: `v0.29`.
- Commits: Conventional Commits via code-commit skill; Chinese description OK.
- Tests import from `../dist/*.js` after `pnpm --filter @typescript-agent-harness/cli build`.

`catalog.ts` text (English, match existing prompts):

```ts
export function buildSkillsCatalogSection(skills: SkillSummary[], opts?: { descriptionMaxLength?: number }): string | undefined {
  const max = opts?.descriptionMaxLength ?? 500;
  const rows = skills
    .filter((s) => s.modelInvocable)
    .slice()
    .sort((a, b) => a.name.localeCompare(b.name))
    .map((s) => {
      const d = s.description.length > max ? s.description.slice(0, max) : s.description;
      return `- ${s.name}: ${d}`;
    });
  if (rows.length === 0) return undefined;
  return [
    "Available skills (progressive disclosure):",
    "Call the skill tool with { name } to load full instructions when a task matches.",
    "Do not reload a skill you already loaded in this turn unless the user asks.",
    "Skills:",
    ...rows,
  ].join("\n");
}
```

`tool.ts`: `name: "skill"`, description explaining progressive load; `execute` looks up summary, checks `modelInvocable`, `loadSkillBody`, `listSkillResources`, `renderSkillContent`.

`slash.ts`: regex `(?:^|\s)/([a-z0-9]+(?:-[a-z0-9]+)*)(?=\s|$)` globally; for each capture in order, if skill exists and `userInvocable`, append rendered content to `modelSuffix` (dedupe same name once per message).
